# Decretum

Decretum is a political decision-making game set in a world inhabited by mythological beings. Players use limited YES and NO stamps, granted by the Goddess of Luck, to approve or reject proposals from different communities. Their decisions shape society and determine one of three possible endings.
 <br> Created for Women Game Jam 2026.

**[Play on itch.io](https://clwramaria.itch.io/decretum)**
